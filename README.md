# UniBudget

UniBudget is a personal finance tracking web application designed to help users manage their monthly spending, income, and expenses in a simple and organized way.

The project was inspired by the need to track everyday expenses such as groceries, transportation, food, entertainment, and other student-related costs.

## Features

- Set a monthly spending limit
- Add and track income
- Add expenses with:
  - name
  - category
  - amount
  - date
- Edit and delete expenses
- Edit and delete income entries
- Monthly expense history
- Category-based monthly spending summary
- Multiple currency support:
  - PLN
  - USD
  - EUR
  - TRY
  - GBP
- User authentication with Supabase
- Continue as Guest option
- Separate local data for guest and authenticated users
- Data persistence using LocalStorage
- Monthly income and expense totals
- Remaining balance calculation

## How It Works

Users can set a monthly spending limit and record both their income and expenses.

Each expense includes a category and date, allowing UniBudget to calculate monthly spending and display category-based summaries.

Users can either create an account using email authentication or continue as a guest.

Guest and authenticated user data are currently stored locally in the browser using LocalStorage.
